# Section A: GDG Portal Review & Suggestions

## Website Reviewed
URL: https://gdgocaitr.vercel.app/

---

## 1. Findings (Glitches & Improvements)

### Mobile View:
* **Layout Alignment:** Elements ke beech spacing mobile screens par thodi uneven lagti hai, jise clean flexbox/grid layout se adjust kiya ja sakta hai.
* **Text Overlap:** Chhoti screen sizes par kuch text titles borders ke paas zyada squeeze ho rahe hain.

### Desktop View:
* **Navigation Bar:** Links ke beech padding improve ho sakti hai taaki hover effect visually better lage.
* **Performance & Asset Loading:** Heavy images aur assets ko optimize (compressed/WebP) karke load time aur fast kiya ja sakta hai.

---

## 2. Constructive Suggestions & Feature Ideas

* **Dark/Light Mode Toggle:** User experience better karne ke liye theme toggle ka option add kiya ja sakta hai.
* **Search & Filter for Events:** Past aur upcoming events ko category/date ke according search ya filter karne ka feature.
* **Interactive UI Animations:** Smooth scroll aur subtle hover animations se site visually aur modern lag sakti hai.
* **Better Call-to-Action (CTA):** Member registration aur event join karne wale buttons ko zyada prominent/highlighted banaya ja sakta hai.
