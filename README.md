# Developer Resource Hub

A dashboard to find, search, and recommend developer tools, sites, and tutorials.

## Features Built
- **Resource Cards:** Categorized resources (Web Dev, App Dev, AI/ML, Tools) with title, description, and link.
- **Live Search & Filter:** Filter resources by keyword/category instantly without page refresh.
- **Add Resource Form:** Simple form to add new resources.
- **Saved Data:** Local storage persistence so data stays after browser refresh.
- **Dark/Light Mode:** Toggle theme for better experience[cite: 1].

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
